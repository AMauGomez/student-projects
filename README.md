# Student projects (2022–2023)

Coursework from my BSc in Mathematics at the Facultad de Ciencias, UNAM, kept here as a record. Each folder has the R Markdown source and the rendered report (in Spanish). These are class exercises on standard teaching datasets; my current work is in the [pinned repositories](https://github.com/AMauGomez).

| Project | Course | Date | Method |
|---|---|---|---|
| [Monte Carlo integration](law-of-large-numbers/) | Probability | Jan 2022 | Approximating integrals with the law of large numbers |
| [Wine data: descriptive analysis](wine-statistical-analysis/) | Multivariate Analysis | Feb 2023 | Exploratory analysis of the UCI Wine dataset |
| [Premier League 2019–20](premier-league-pca/) | Multivariate Analysis | Apr 2023 | Principal component analysis of team statistics |
| [Perception of pain](pain-perception-factor-analysis/) | Multivariate Analysis | Apr 2023 | Factor analysis from a correlation matrix |
| [Cancer cell lines](cancer-cell-clustering/) | Multivariate Analysis | May 2023 | Hierarchical and k-means clustering of the NCI60 microarray data |
| [S&P 500 daily returns](sp500-discriminant-analysis/) | Multivariate Analysis | May 2023 | Linear and quadratic discriminant analysis |
| [CEMEX stock price](cemex-time-series/) | Survival and Time Series Models | May 2023 | Time-series modelling and forecasting |

Originally published as separate repositories in 2024 and consolidated here in November 2026.
